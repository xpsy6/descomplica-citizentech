# descomplica-citizentech
O Descomplica é um site feito para facilitar o acesso a informações sobre serviços públicos. Muitas pessoas, principalmente idosos e jovens que estão começando a lidar com documentos e benefícios, têm dificuldade para entender por onde começar nos serviços digitais do governo.

No site, o usuário conversa com o Brasileirinho, um assistente que mostra orientações sobre 10 temas, como RG, Cadastro Único, Bolsa Família, SUS, Carteira de Trabalho e Seguro-desemprego. Para cada tema, ele explica para quem é, quais documentos levar, o passo a passo e os canais oficiais para consultar.

O projeto também tem histórico de perguntas, favoritos, formulário com validação, ajuste de tamanho de texto e modo de alto contraste. Foi feito com HTML, CSS e JavaScript e está ligado aos ODS 10 (Redução das desigualdades) e 11 (Cidades e comunidades sustentáveis).

É um projeto acadêmico e não substitui os canais oficiais do governo.
